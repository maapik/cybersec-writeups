# Duckerz CTF — DoS-логи (Анализ веб-логов)

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | Duckerz CTF |
| **Категория** | Forensics / Web Log Analysis |
| **Уровень** | Easy |

## Описание

Дан массивный лог-файл веб-сервера, снятый во время DoS-атаки. Среди миллионов мусорных запросов спрятаны фрагменты флага.

## Решение

Фильтруем шум и находим аномальные `PUT`-запросы вида:
```text
PUT /flag.php/<часть_флага>
```

После `/flag.php/` передаются фрагменты флага — извлекаем их по порядку (например, через `grep` / `awk`) и склеиваем в итоговый флаг.

**Флаг:** `DUCKERZ{4n4lyz1n6_7h3_w3b_l06}`
