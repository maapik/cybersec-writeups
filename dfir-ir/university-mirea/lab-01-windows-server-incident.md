# Лабораторная работа №1 (РТУ МИРЭА) — Расследование инцидента на Windows Server

| Параметр | Значение |
| :--- | :--- |
| **Площадка** | РТУ МИРЭА (учебная лаборатория по компьютерной экспертизе) |
| **Категория** | Windows Forensics / Event Log Analysis (`.evtx`) |
| **Журналы** | `System.evtx` (Event ID `7045`), `Security.evtx` (Logon / Privileges) |

## Постановка задачи

Ночью системный администратор проводил плановое обновление Windows Server. По его словам, на момент завершения работ серверы функционировали штатно. Однако после инцидента с серьёзным ущербом руководство передало собранные лог-коллектором журналы событий.

**Цели экспертизы:**
1. Определить характер вредоносного ПО (драйвер / служба / фильтр) и его название.
2. Восстановить хронологию событий той ночи.
3. Установить причастность/виновность администратора по логам системы.

### 1. Определение Event ID установки новой службы
Поскольку в вводных фигурируют драйвер и служба, ищем события установки новых служб в Windows — это **Event ID `7045`** в журнале `System`:

### 2. Поиск вредоносного драйвера в журнале `System`
Фильтруем `System` по коду `7045` и находим регистрацию неизвестного драйвера в **01:25:45**:

Переходим в журнал `Security` и фильтруем по событиям входа (`Logon`). В **01:19:50** зафиксирован **физический/интерактивный вход** в систему под новой учётной записью:

## Вывод

Согласно условиям инцидента, физический доступ к серверам в указанное ночное время имел исключительно системный администратор. Поскольку вход в `01:19:50` был интерактивным, за ним последовала выдача привилегий на загрузку драйверов, установка Chrome (`01:21:36`) и скачивание/установка вредоносного драйвера (`01:25:45`), администратор либо действовал умышленно сам, либо нарушил регламент, допустив постороннее лицо к серверу. Виновность подтверждена хронологией журналов `Security` и `System`.
