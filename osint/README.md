## Краткое содержание отчёта

Разбор реального инцидента с использованием социальной инженерии и поддельного портала «Госуслуги»:

1. **Вектор атаки (Social Engineering):** установление контакта в мессенджере, маскировка фишингового URL под стандартную инвайт-ссылку Telegram.
2. **Анализ фишинг-панели в изолированной среде (Sandbox / VMware):** разбор схемы с поддельным уведомлением о несанкционированном доступе и таргетированной сессией по `?user_id=...`.
3. **OSINT и проверка индикаторов (IOCs):** проверка поддельной почты (использование реквизитов легитимного ИП в качестве прикрытия) и атрибуция виртуальных номеров.
4. **Incident Response:** фиксация IOCs, анализ ограничений сервера и отправка жалоб (abuse-репортов) на использованную инфраструктуру.
