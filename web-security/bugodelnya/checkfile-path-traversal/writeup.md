# BUGodelnya — `checkFILE` (Path Traversal)

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | BUGodelnya CTF |
| **Категория** | Web (Path Traversal / LFI) |

## Решение

1. Открываем веб-приложение и вводим путь `/app/allowed/fake_flag`, чтобы увидеть, как формируется URL чтения файла (`/read?file=...`).
2. Применяем **Path Traversal** (выход из разрешённой директории с помощью последовательности `../`), поднимаемся выше по дереву каталогов и указываем путь к целевому файлу:

```text
http://31.207.77.216:4013/read?file=../../../../app/forbidden/flag.txt
```

## Пояснение уязвимости

Сервер недостаточно строго валидирует путь в GET-параметре `file`. Последовательность `../` позволяет выйти за пределы корневой/разрешённой директории приложения и обратиться к `/app/forbidden/flag.txt` (важно подобрать достаточное количество переходов `../` вверх).
