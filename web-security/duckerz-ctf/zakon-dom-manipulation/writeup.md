# Duckerz: Юридический квест

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | Duckerz CTF |
| **Категория** | Web (JS DOM Manipulation) |
| **Уровень** | Easy |

## Описание

Кнопка «Принять» убегает от курсора мыши при наведении — клиентская проверка. Необходимо подтвердить ознакомление со статьёй 272 УК РФ, чтобы получить флаг.

## Решение

Вызываем клик по кнопке напрямую из консоли DevTools (`F12`):

```js
document.getElementById('accept').click()
```
