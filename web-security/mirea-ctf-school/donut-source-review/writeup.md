# Donut Design — Анализ исходного кода страницы

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | МИРЭА CTF School |
| **Категория** | Web (Source Code Review) |
| **Уровень** | Easy |

## Описание

Веб-приложение по моушн-дизайну с темами glitch, noir и pixel, где центральным элементом выступает пончик. Флаг спрятан в одном из клиентских ресурсов.

## Решение

1. Открываем страницу и переходим в режим просмотра исходного кода (`Ctrl+U` / **View Page Source**).
2. Находим подключённый скрипт (например, `/script.js`).
3. Просматриваем содержимое JS-файла до конца и находим флаг прямо в комментарии или переменной.
