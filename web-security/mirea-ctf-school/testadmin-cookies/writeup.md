# Cookie Admin — Подмена роли в Cookies

| Параметр | Значение |
| :--- | :--- |
| **Платформа** | МИРЭА CTF School |
| **Категория** | Web (Cookie Tampering) |

## Описание

Веб-страница при открытии выводит сообщение `"You are not an admin"`. При проверке хранилища браузера обнаруживается, что роль пользователя хранится на стороне клиента в cookie.

## Решение

1. Открываем **DevTools (`F12`) → Application / Storage → Cookies** и выбираем домен сайта.
2. Находим параметр `is_admin=false`.
3. Редактируем значение cookie на `is_admin=true`.
4. Обновляем страницу — сервер считывает привилегированную роль и отображает флаг.
